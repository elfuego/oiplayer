OIPlayer video & audio player

Plain vanilla Javascript HTML5 audio and video player

Storm, by Polygoon-Profilti (producer) / Netherlands Institute for Sound and Vision (curator), is licensed under Creative Commons – Attribution-Share Alike.

Jump to 1 minute and 11 seconds where one of Scheveningen's fishing ships rides the waves and "surfs" home into the harbour. You can find the video on Open Images http://www.openimages.eu/media/9728/Storm.

OIPlayer 'attaches' itself to all video and/or audio tags it encounters. Besides the general configuration of the plugin itself, it uses for each individual tag the attributes the respective tag has like poster, width, controls, autoplay etc. Easy implementation: 

  new OIPlayer(document.getElementById("my-media"));

Download

  • Download the most recent version from GitHub.

Features

  • Plays video as well as audio
  • Easy to use and implement
  • Consistent look between browsers
  • Multiple different players on a page
  • Play/pause
  • Mute/unmute
  • Full 'screen' (full window really, that is what HTML5 requires)
  • Dark and light controls, on top or below player
  • Easily skinnable with css
  • Fires events: 'oiplayerplay' and 'oiplayerended' to use f.e. for play statistics

OIPlayer's configuration accepts the following options. The controls value is a space-separated string combining placement (top or omit for below) and theme (dark or omit for light): 

new OIPlayer(el, { controls: "top dark" });  // dark controls on top
new OIPlayer(el, { controls: "top" });       // light controls on top
new OIPlayer(el, { controls: "dark" });      // dark controls below
new OIPlayer(el, {});                        // light controls below (default)

OIPlayer is part of the Open Images Platform which is MMBase based. OIPlayer's most recent sources can be found on GitHub: https://github.com/elfuego/oiplayer. It is licensed under GPL.

How-to

  1. Download and copy the 'oiplayer' directory to your site. Include these Javascript and css files in the head of your html document. 
    <script defer src="js/oiplayer.js"></script>
<link href="css/oiplayer.css" rel="stylesheet" />
  2. Initialize OIPlayer on a specific element, or on all video/audio tags in a container. 
    // single element
new OIPlayer(document.getElementById("my-media"), { controls: "top" });

// all video and audio in a container
const media = document.querySelectorAll(".my-player video, .my-player audio");
media.forEach((el) => new OIPlayer(el, { controls: "top" }));
  3. Besides these you can identify your player with a unique id f.e. with 'oip_ea_id_myid123', which is registered in 'player.id'. This can be useful for example to track the number of plays of a media item. OIPlayer fires two events to this effect: 'oiplayerplay' and 'oiplayerended', f.e.: 
    window.addEventListener("oiplayerplay", (ev) => {
  console.log("oiplayerplay event", ev.detail);
});

Yesteryear

  1. OIPlayer had a fallback mechanism that could be made to work by installing Flowplayer and Cortado. Flowplayer needed the Flash plugin and plays h.264, flv and mp4. Cortado is a Java applet that plays Ogg video and audio (ogv, oga).
    The framework is still there in this version, but there is no use since Java applets and Flash are no longer supported.
